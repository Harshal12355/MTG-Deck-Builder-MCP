## Overview
~$100 high-power Boros Balloon Man rebuilt for **Clamp + burn density**. This is not "cute balloons and hope." Every balloon should draw (Skullclamp / Idol / Enduring Innocence) and ping (Tremors / Gatekeeper / Roastmaster / Arabella / Raid). Late Bell-Ringer / Recruiter infinites are a bonus, not the only plan.

## Game plan
Turn 1–2: land + dork or rock. Turn 3: Balloon Man (haste) + copy an ETB or equip Clamp to a 1/1. Turn 4–5: land a burn outlet and keep making balloons; Clamp turns end-step sacrifices into cards so you find the next piece.

## Mulligan
Keep 2–5 lands with one cheap mana source (dork or rock). Ship hands with no red/white by turn 2, or no path to Balloon Man by turn 4. Clamp or a burn enchantment in the opener is a strong keep.

## Win conditions
- Balloon Man + any ETB/attack burn (Impact Tremors, Molten Gatekeeper, Witty Roastmaster, Weftstalker Ardent, Raid Bombardment, Arabella, Goblin Bombardment) → table damage from every balloon
- Balloon Man + Village Bell-Ringer / Sparring Mummy + mana creature → infinite hasty balloons (burn finishes)
- Balloon Man + Coercive Recruiter + mana creature → same loop via Pirate ETB untaps
- Balloon Man + Ertha Jo + Zealous Conscripts + mana creature → ability-copy loop
- Combat Celebrant + Determined Iteration → extra combats into Raid/Arabella damage

## How the lines work
- **Clamp engine:** balloons are 1/1s that die at end step. Equip Skullclamp → die → draw 2. Idol draws if you made a token; Enduring Innocence draws once per turn off power ≤2 enters.
- **Burn clock:** cast Tremors / Gatekeeper / Roastmaster, then every Balloon Man activation is 3 damage to the table (or more with multiples).
- **Bell-Ringer / Sparring Mummy:** tap dork for {1}, copy the untapper, untap BM + dork, repeat (sorcery speed only).
- **Recruiter:** copy makes Pirate balloons; each Recruiter ETB can untap BM and the dork.
- **Marvin:** shares BM's activated ability so you get a second copy button without finding an untapper.

## Key cards
- **Skullclamp** — the consistency card Archidekt runs at 100%; turns dead balloons into gas
- **Idol of Oblivion / Enduring Innocence** — draw engines that fire off the tokens you already make
- **Impact Tremors / Molten Gatekeeper / Witty Roastmaster** — the primary kill
- **Arabella, Abandoned Doll / Raid Bombardment** — balloons attack with haste; combat burn without needing another enchantment
- **Hedron Crawler / Manakin / Iron Myr / Gold Myr** — {1} fuel with no life tax (Myr Convert is gone)
- **Sparring Mummy** — cheap Bell-Ringer twin so the untap slot is not a 1/0/0 pigeon
- **Marvin, Murderous Mimic** — extra Balloon Man activations
- **Circuit Mender** — copy it; EOT sac draws (and Clamp draws more)
